# Global Conflict Analytics — Case Study

An academic business-intelligence case study focused on exploring the relationship between armed
conflict events and international arms-transfer indicators.

## Scope

The project combined conflict-event and arms-transfer data in an interactive analytical dashboard.
The intended experience was to let a user inspect geography, time periods, actors and indicators
through linked visualisations.

This repository is deliberately documentation-only. The original Power BI workbook and source data
are not shared because a workbook can embed data, model contents and connection information.

## Analytical themes

- temporal patterns in conflict activity;
- geographic comparison of events and locations;
- arms-transfer indicators by country or relationship;
- linked filters and drill-down exploration;
- visual storytelling for a non-technical audience.

## Privacy and publication boundary

The following are intentionally excluded:

- the PBIX workbook and any data model embedded in it;
- source datasets and transformations;
- exported visuals and report files;
- source links that have not been cleared for redistribution;
- personal contact details and local environment information.

## Status

This private repository acts as a safe portfolio placeholder. A future public version would need
either a clean, reproducible data pipeline using openly licensed sources or static visual material
that is expressly cleared for publication.
